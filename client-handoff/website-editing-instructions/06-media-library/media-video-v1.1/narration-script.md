## Scene 1 — Upload and use images in the Media Library

This lesson shows you how to prepare an approved image, upload it to the WordPress Media Library, write useful alt text, place it in the correct content item, save safely, and verify the public result without deleting media that another page may still use.

## Scene 2 — Required WordPress access

You need an Editor or Administrator account. Editor is enough for routine image uploads and placement. Do not delete existing media, install image tools, change upload settings, or use an Administrator account merely because an upload or menu looks different.

## Scene 3 — Prepare the image before opening WordPress

Gather the one approved final image. Confirm its subject, permission, crop, and web-ready size. Never upload private records, unlicensed images, screenshots containing personal information, or a file you cannot identify. Stop when the image source or intended use is uncertain.

## Scene 4 — Open the Media Library and choose Add New

Open Media, then Library, and select Add New Media File. Upload only the approved final image. Do not upload several guesses for someone else to sort out. One clear asset is easier to find, use, and maintain.

## Scene 5 — Use a clear filename before uploading

Rename the file on the computer before uploading it. Use short lowercase words separated by hyphens that describe the subject. Avoid names such as final-final, image-one, or a camera number. Keep the correct file extension, such as J P G, P N G, or Web P.

## Scene 6 — Choose the file and wait for the upload

Select the exact approved file. Wait until the progress indicator finishes and the attachment appears. If WordPress reports an error, stop and read it. Do not click repeatedly or upload the same file with different names, because that creates duplicates.

## Scene 7 — Write alt text for the image's purpose

Open the attachment details and write alt text that describes the important subject or purpose in one short phrase or sentence. Leave alt text empty only when the image is purely decorative. Do not copy the filename or stuff keywords, locations, and services.

## Scene 8 — Use title, caption, and description carefully

Give the Media Library item a readable title so staff can identify it. Add a caption only when words should appear publicly under the image. Use Description only when the site process specifically needs it. A caption is public content, not a private staff note.

## Scene 9 — Insert media from the content or image control

Open the exact page, post, event, or practitioner and its image control. Choose the uploaded image by its thumbnail and title. Use the intended size and preserve the natural proportions. Do not drag the image wider or taller in a way that stretches it.

## Scene 10 — Replace an image without breaking old pages

Upload an approved replacement as a new file unless Blue Nova provides a verified replacement tool. Update the exact content item to use the new image. Do not delete the old Media Library file, because another page or an older link may still use its address.

## Scene 11 — Save once and clear only the applicable cache

Review the crop, alt text, and placement. Select Save or Update one time and wait for confirmation. Clear only the applicable page or record cache. Do not purge unrelated content and do not change image, cache, plugin, or server settings.

## Scene 12 — Verify the public image on desktop and phone

Open the exact public page. Confirm the correct image loads, remains sharp, and is not stretched, blurry, or cropped badly. Check it at phone size and test any linked image. A successful Media Library upload does not prove the public placement is correct.

## Scene 13 — Always finish with the final verification

Always finish by uploading one approved file, adding useful alt text, placing it in the exact content item, saving once, clearing only the applicable cache, and verifying the public image on desktop and phone. Stop and contact Blue Nova before deleting or replacing uncertain media.
