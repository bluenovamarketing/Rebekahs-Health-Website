# Upload and Use Images in the Media Library

**Version:** v1.1  
**Required role:** Editor or Administrator; Editor is sufficient

## Prepare the file

- Confirm the image is approved, licensed, and free of private information.
- Confirm the intended crop and web-ready size.
- Rename before uploading: short lowercase words separated by hyphens.
- Keep the correct `.jpg`, `.png`, or `.webp` extension.

## Upload and describe

1. Open **Media > Library > Add New Media File**.
2. Select the exact approved file and wait for the upload to finish.
3. Stop and read any upload error; do not create duplicates.
4. Add concise alt text describing the important subject or purpose.
5. Use a readable Media Library title.
6. Add a Caption only when it should appear publicly.
7. Use Description only when the site process requires it.

## Place and verify

1. Open the exact content item and its image control.
2. Choose the correct Media Library thumbnail and intended size.
3. Preserve the natural proportions; do not stretch the image.
4. For replacement, upload the new approved file and update the exact content item.
5. Do not delete old media without Blue Nova review.
6. Save or Update once and clear only the applicable cache.
7. Verify sharpness, crop, placement, and linked-image behavior on the exact public page at desktop and phone sizes.

**Always finish with: Upload once > alt text > place correctly > save once > clear applicable cache > verify publicly.**
