# Update an Existing Practitioner Listing

Rebekah's Health & Nutrition — beginner checklist, v1.3

## Access required

- WordPress role: **Editor** or **Administrator**.
- Recommended for routine staff: **Editor**.
- Live login: `https://rebekahspureliving.com/wp-admin`

## Before editing

- Gather the approved name, credentials, practice, area of practice, description, and public contact information.
- Confirm the address begins with `rebekahspureliving.com/wp-admin`.
- Do not work from a future staging-site login when the live site needs to change.

## Edit the record

1. Select **Medical Practicioners** in the left menu.
2. Select **All Medical Practicioners**.
3. Find or search for the correct person.
4. Hover over the correct row and select **Edit**.
5. Scroll to **Medical Practicioner Fields**. If needed, select **Meta Boxes** and enlarge the section with **Drag to resize**.
6. Update only the approved fields:
   - **Medical Service** — approved area or areas of practice.
   - **Medical Center** — public practice or business name.
   - **Medical Practitioner Full Name** — public name and credentials.
   - **Medical Practitioner Description** — select **Visual** first.
   - **Medical Practitioner Contact Info** — select **Visual** first; publish only approved public details.
7. Recheck spelling, credentials, first and last description lines, and links.
8. Select the blue **Save** button once and wait for confirmation.

## Finish every edit

1. Return to **All Medical Practicioners**.
2. Hover over the updated row and select its **Clear Cache** action.
3. Open `https://rebekahspureliving.com/practitioners/` with no extra code after the slash.
4. Search for the updated person.
5. Check the card, then select **View full listing**.
6. Confirm the result on desktop and phone, including all public links.

## Stop and ask Blue Nova if

- The requested category does not exist.
- You are unsure which field to change.
- WordPress displays an error.
- The public page still shows old information after the record cache is cleared.
- The layout breaks, text is cut off, or a link does not work.

**Always finish with: Save → Clear the applicable cache → Verify the exact public page on desktop and phone.**
