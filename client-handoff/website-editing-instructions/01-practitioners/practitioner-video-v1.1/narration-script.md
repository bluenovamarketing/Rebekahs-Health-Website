# How to Update an Existing Practitioner Listing in WordPress

Pilot draft v1.1 — Rebekah's Health & Nutrition

## Scene 1 — What this video covers

In this video, I will show you how to update an existing practitioner listing on Rebekah's live website. We will find the correct record, change only the information that needs to be changed, save it, clear the applicable cache, and confirm the result on the public Practitioners page. This video does not cover adding a brand-new practitioner. That will be a separate lesson.

## Scene 2 — Before you begin

You need a WordPress account with the Editor or Administrator role. An Editor is the recommended role for a staff member who only needs to update website content. Do not give someone Administrator access just so they can edit practitioner listings. Administrator access includes settings and controls that routine editors do not need.

Have the approved replacement information ready before you sign in. For example, have the correct practitioner name, practice name, area of practice, description, and contact information in one document so you can copy it carefully.

## Scene 3 — Sign in to the live website

Open your browser and go to rebekahspureliving.com slash wp-admin. Enter your own WordPress username and password, and then select Log In. Never share one person's login with another person. If a staff member needs access, an Administrator should create a separate account for that person. Account creation is covered in a separate video.

Before continuing, look at the web address and confirm that it begins with rebekahspureliving.com slash wp-admin. This keeps you from accidentally editing a future staging website instead of the live website.

## Scene 4 — Open the practitioner list

In the dark menu on the left, select Medical Practicioners. On this website, the menu label is currently spelled Practicioners. Then select All Medical Practicioners. You will see a list of the existing practitioner records.

If the list is long, use the Search Medical Practicioners box in the upper-right corner. Type part of the practitioner's name, and then select Search Medical Practicioners.

## Scene 5 — Open the correct record

Find the correct name in the list. Move your pointer over that row and select Edit. Do not select Quick Edit, Trash, or Clear Cache at this point. Also confirm that you are opening the correct person before you make any changes. In this example, we are only using Laura Young's record to demonstrate where the fields are. We are not changing her live information.

## Scene 6 — Find the practitioner fields

Wait for the editing screen to finish loading. The blue button in the upper-right corner says Save when the record is already published.

Scroll down to the Medical Practicioner Fields section. If you cannot see that section, select Meta Boxes near the bottom of the editor. If the section is still too small, use the Drag to resize divider directly above it and move the divider upward until the fields are visible. Do not change anything else on this screen.

## Scene 7 — Choose the area of practice

The first field is Medical Service. Select the checkbox that matches the practitioner's approved area of practice. Leave every unrelated checkbox alone. If the practitioner belongs in more than one category, select only the categories that have been approved. Do not guess. Ask before adding a new category or changing the category names.

## Scene 8 — Update the practice and full name

The Medical Center field is the public practice or business name. Click inside the box, select the old text, and type or paste the approved practice name.

The Medical Practitioner Full Name field is the name shown in the public directory. Click inside that box, select the old text, and type or paste the full approved name, including credentials exactly as they should appear. Check the spelling, punctuation, spaces, and credential letters one character at a time.

## Scene 9 — Update the description

Find Medical Practitioner Description. Select the Visual tab before editing. Do not use the Text tab unless Blue Nova specifically asks you to edit HTML code.

Click in the description, select only the text you intend to replace, and paste the approved description. Read the first sentence and the last sentence after pasting. This catches missing text and accidental extra paragraphs. Do not paste a different font, color, or oversized heading into this field.

## Scene 10 — Update contact information

Find Medical Practitioner Contact Info and select the Visual tab. Enter only the contact information that has been approved for public display, such as a website, email address, telephone number, or location.

To create a clickable link, select the words that should be linked, choose the link button, paste the complete web address beginning with H T T P S, and apply the link. For an email link, use the approved email address. Never publish private contact information.

## Scene 11 — Review before saving

Before selecting Save, review every field you touched. Confirm the area of practice, practice name, full name and credentials, first and last lines of the description, and each public contact link.

Do not change the page address, WordPress settings, SEO fields, code, or any field that was not part of the requested update. If anything looks wrong or you are unsure, stop before saving and ask Blue Nova.

## Scene 12 — Save the record

When everything is correct, scroll to the top and select the blue Save button once. Wait for WordPress to finish. Do not click repeatedly. Look for the saved confirmation before leaving the page.

If WordPress shows an error, copy the error message or take a screenshot and contact Blue Nova. Do not keep pressing Save, refresh the page, or re-enter the information until the error is understood.

## Scene 13 — Clear the applicable cache

Return to All Medical Practicioners. Find the record you just updated, move your pointer over its row, and select Clear Cache for that record. Do not use Purge All Cache, Purge Varnish Cache, or other server-wide cache controls unless the separate cache-clearing lesson tells you to do so.

Clearing the record's applicable cache helps the saved change appear to visitors. Seeing the new information inside WordPress is not enough; you must check the public page.

## Scene 14 — Verify the exact public page

Open a new browser tab and go to rebekahspureliving.com slash practitioners slash. Do not add a question mark or a cache-busting code to the address.

Use the Search by name, practice or city box to find the person you updated. Confirm the public name, credentials, practice, area of practice, description preview, and any visible location.

## Scene 15 — Open the full listing and check a phone

Select View full listing and confirm the full description and contact information. Test each visible website, email, and telephone link.

Finally, check the same public page on a phone or at a narrow browser width. Make sure the card fits the screen, the text is readable, and every link works. If the old information still appears, stop and contact Blue Nova rather than changing the record again.

## Scene 16 — The closing routine

Every website editing video in this library ends with the same three checks: Save the change. Clear the applicable cache. Open the exact public page and confirm the result on desktop and phone.

If all three checks pass, the practitioner update is complete. If any check fails, take a screenshot and contact Blue Nova before making another change.
