## Scene 1 — Add a new practitioner or practice listing

This lesson shows you how to add one new practitioner or practice to the website directory. We will work carefully, keep the new record unpublished until it is complete, save only once, clear the applicable cache, and confirm what visitors can actually see on the live Practitioners page.

## Scene 2 — Required WordPress access

You need a WordPress account with the Editor or Administrator role. Editor access is enough for this task. If you do not see Medical Practicioners in the left menu, stop and ask the website administrator for help. This lesson does not create or change user accounts.

## Scene 3 — Sign in to the live website

Open a web browser and go to rebekahspureliving.com forward slash W P dash admin. Enter your own username and password, then select Log In. Make sure the address begins with rebekahspureliving.com. Do not use an old staging address.

## Scene 4 — Open the practitioner list

In the black menu on the left, select Medical Practicioners. The unusual spelling is the label used inside this WordPress website. Then select All Medical Practicioners. You should now see the existing directory records and the Add New Medical Practitioner button near the top.

## Scene 5 — Start one new record

Select Add New Medical Practitioner one time. Create only one record for the approved listing. If the listing represents a clinic or team, one practice record can contain the practice name and the approved team information. Do not create a separate duplicate record for every person unless that is specifically requested.

## Scene 6 — Keep it as a draft

The new record should remain a draft while you work. Do not publish an empty or incomplete listing. Scroll to Meta Boxes and open Medical Practicioner fields. If those fields are missing, stop. Do not place the information in unrelated WordPress boxes.

## Scene 7 — Choose the medical service

Find Medical Service. Check only the approved service category or categories. Read the complete list before choosing. Do not guess, create a new category, or select every category. The categories control how the listing appears when visitors filter the public directory.

## Scene 8 — Enter the practice and public name

In Medical Center, enter the approved practice or organization name. In Medical Practitioner Full Name, enter the exact public name that should appear on the directory card. For a practice listing, use the approved practice or team display name. Match spelling, credentials, punctuation, and capitalization exactly.

## Scene 9 — Add the approved description

Find Medical Practitioner Description and select the Visual tab. Enter or paste the approved public description. Preserve the paragraph breaks so the text is easy to read. Do not add private health information, internal notes, unapproved claims, or information copied from another listing.

## Scene 10 — Add public contact details

Find Medical Practitioner Contact Info. Add only information approved for public display, such as the website, public email address, public phone number, and location. Make each link point to the correct destination. Remove placeholders and do not publish a private email address or personal phone number by accident.

## Scene 11 — Review every field

Before publishing, read every field from top to bottom. Confirm the service category, practice name, public name, description, phone number, email address, website, and location against the approved information. Correct every typo now. If anything is uncertain, leave the record as a draft and ask before publishing.

## Scene 12 — Publish once and wait

When every required field is complete and approved, select Publish or Save one time. Wait for WordPress to confirm that the record was saved. Do not click repeatedly. Repeated clicks can create confusion or duplicate actions. If WordPress reports an error, read it before doing anything else.

## Scene 13 — Clear the applicable cache

Return to All Medical Practicioners. Find the new record and hover over its row. If Clear Cache is available for that record, select it once. If the site also shows an approved Breeze or Varnish purge control, clear only the applicable cache. Do not change unrelated server or optimization settings.

## Scene 14 — Verify the public directory

Open the exact public address, rebekahspureliving.com forward slash practitioners forward slash, without adding anything to the address. Search for the new name, practice, or city. Confirm that the correct card appears, the category and city are correct, and the public details match the approved information.

## Scene 15 — Check the full listing and a phone

Select View full listing on the directory card. Confirm that the expanded details, phone number, website, email, and description are visible and usable. Then repeat the check at a phone-size screen. There is no separate public practitioner page to manage; visitors use the Practitioners directory and its expanded listing.

## Scene 16 — Always finish the same way

Every practitioner change ends with the same three checks. First, save the correct record. Second, clear only the applicable cache. Third, verify the exact public Practitioners page on desktop and phone. If the live result is wrong or missing, stop and ask for help instead of making random changes.
