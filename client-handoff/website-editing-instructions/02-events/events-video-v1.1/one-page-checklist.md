# Create or Update an Event

Required access: WordPress Editor or Administrator. Editor is enough.

1. Go to `https://rebekahspureliving.com/wp-admin` and sign in with your own account.
2. Select **Events**.
3. For a new event, select **Add New Event**. For an update, find the correct title and select **Edit**.
4. Keep a new event as a **Draft** until every required detail is complete.
5. Enter the exact approved title and complete public description in **Visual** mode.
6. Choose the correct store category: **Clarkston, Grand Blanc, Lake Orion, or Lapeer**.
7. Enter the start and end dates and times. Use **All Day** only when appropriate.
8. Confirm the **America/Detroit** time zone.
9. Choose an existing venue and organizer when possible.
10. Add the cost, external event website when needed, and a 16:9 featured image with alt text.
11. Preview the event at desktop and phone size. Fix every incorrect or missing detail.
12. Select **Publish** or **Update** once and wait for confirmation.
13. For a canceled announced event, set **Events Status → Canceled**, add a clear cancellation note, and update it. Do not immediately delete it.
14. Clear only the applicable page, record, Breeze, or Varnish cache.
15. Open `https://rebekahspureliving.com/events/` with no extra address text.
16. Find and open the event. Check the title, store, date, time, image, details, and every public link.
17. Repeat the check on a phone-size screen and confirm nothing runs off the side.

This lesson does not include user-account management, event tickets, or RSVP setup.

Always finish: **SAVE → CLEAR APPLICABLE CACHE → VERIFY LIVE**
