## Scene 1 — Create or update an event

This lesson shows you how to create a new event or update an existing event on the live website. We will work as a draft, enter every required detail, preview the result, save it safely, clear the applicable cache, and verify what visitors can see on the public Events page.

## Scene 2 — Required WordPress access

You need a WordPress account with the Editor or Administrator role. Editor access is enough for this task. If Events is missing from the left menu, stop and ask the website administrator for help. This lesson does not create users, change roles, or manage passwords.

## Scene 3 — Sign in to the live website

Open a web browser and go to rebekahspureliving.com forward slash W P dash admin. Enter your own username and password, then select Log In. Confirm that the address is the live rebekahspureliving.com domain. Do not use an old staging address.

## Scene 4 — Open Events

In the black menu on the left, select Events. To create a new event, select Add New Event. To update an event, stay on the Events list, find the correct title, and select Edit. Always confirm that you opened the correct event before changing anything.

## Scene 5 — Add the title and description

For a new event, enter the exact approved title. In the main Visual editor, enter the complete public description, including what the event is, who it is for, and any instructions visitors need. Select Save Draft while you work. Do not publish an event that is missing required information.

## Scene 6 — Choose the store category

In Event Categories, check the store location connected to the event: Clarkston, Grand Blanc, Lake Orion, or Lapeer. Choose only the correct location. Do not create a new category or guess. The category helps visitors find events for the store they plan to visit.

## Scene 7 — Complete every event detail

Enter the start date, start time, end date, and end time. Use All Day only when it is truly an all-day event. Confirm the America slash Detroit time zone. Choose an existing venue and organizer when possible. Add the cost, external event website if needed, and a sixteen-by-nine featured image with useful alt text.

## Scene 8 — Preview before publishing

Select Preview and inspect the event before publishing. Confirm the title, description, store, date, time, venue, organizer, cost, link, and image. Check the preview at desktop and phone size. If anything is wrong or uncertain, return to the editor, correct it, and keep the event as a draft.

## Scene 9 — Publish, update, or cancel safely

When a new event is complete and approved, select Publish one time and wait for confirmation. For an existing event, select Update one time. If an announced event is canceled, set Events Status to Canceled, add a clear cancellation note to the description, and update it. Do not immediately delete an announced event.

## Scene 10 — Clear the applicable cache

After saving, return to the Events list. Find the event you changed. Clear the applicable page or record cache if that option is available. If the site provides an approved Breeze or Varnish purge control, use only the applicable purge. Do not change unrelated cache, server, or optimization settings.

## Scene 11 — Verify the public Events page

Open rebekahspureliving.com forward slash events forward slash without adding anything to the address. Find the event using the location filter or the event list. Confirm that the title, date, time, store, image, and link are visible and correct. Open the event itself and test every public link.

## Scene 12 — Repeat the check on a phone

Repeat the public check at a phone-size screen. Make sure the location filter opens, the event card fits the screen, the text is readable, and no content runs off the side. A successful WordPress save does not prove that a visitor can see or use the event on the live website.

## Scene 13 — Always finish the same way

Every event change ends with the same three checks. First, save or update the correct event. Second, clear only the applicable cache. Third, verify the exact public event and Events page on desktop and phone. If the live result is wrong or missing, stop and ask for help instead of making random changes.
