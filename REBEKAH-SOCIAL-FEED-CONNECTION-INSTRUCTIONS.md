# Connect Rebekah's Instagram and TikTok Feeds

These instructions connect Rebekah's social accounts to the website so new public posts, Reels, and TikTok videos can appear automatically. The two feed plugins are already installed. You do not need to install anything or edit the Homepage.

Please do this on a desktop or laptop after Blue Nova confirms the website is on its permanent domain.

## Before you begin

- Have access to the WordPress administrator account for `rebekahspureliving.com`.
- Be able to sign in to Instagram account `@rebekahs_health_and_nutrition`.
- Be able to sign in to TikTok account `@rebekahspureliving`.
- If Instagram is connected through Meta, be able to access the Facebook account/Page that manages that Instagram profile.
- Use the same browser for the entire process and allow pop-ups or redirects from WordPress, Smash Balloon, Instagram/Facebook, and TikTok.

You will authorize each account through its official sign-in screen. Do not email or text your Instagram, Facebook, or TikTok password to Blue Nova.

## 1. Connect Instagram

1. Sign in to the WordPress dashboard for `rebekahspureliving.com`.
2. In the left menu, select **Instagram Feed > All Feeds**.
3. Select **Add New**.
4. Choose **User Timeline**, then select **Next**.
5. Select **Add Source**, then **Add New**.
6. Choose the account type that matches the profile. For Rebekah's business/creator profile, use the **Business** or **Professional** option if it is shown.
7. Select **Connect** or **Login with Facebook/Instagram**.
8. Sign in on the official Instagram or Facebook screen if prompted. Approve the requested permissions; removing permissions can prevent the feed from updating.
9. Select the Facebook Page/Instagram profile connected to `@rebekahs_health_and_nutrition`, then select **Add** or **Next**.
10. Confirm that the source shown in WordPress is `@rebekahs_health_and_nutrition`.
11. Name the feed **Homepage Instagram** and select **Save**.

Do not use the **Embed** button or edit the Homepage. Blue Nova will place and style the saved feed in the approved Homepage section.

Official reference: [Setting up the free Instagram Feed plugin](https://smashballoon.com/doc/setting-up-the-free-instagram-feed-wordpress-plugin/)

## 2. Connect TikTok

1. In the WordPress dashboard's left menu, select **TikTok Feeds > All Feeds**.
2. Select **Add New**, then **Add Source**.
3. On the Smash Balloon connection screen, select **Connect with TikTok**.
4. On TikTok's official authorization screen, sign in to `@rebekahspureliving` if prompted and select **Authorize**.
5. When the website domain is displayed, make sure it is the permanent Rebekah's website and select **Yes, it is my domain**.
6. Select the `@rebekahspureliving` account and choose **Next**.
7. Choose the **Default** template and select **Next**.
8. Name the feed **Homepage TikTok** and select **Save**.

Do not use the **Embed** button or edit the Homepage. Blue Nova will place and style the saved feed in the approved Homepage section.

Official reference: [Creating a feed with the free TikTok Feeds plugin](https://smashballoon.com/doc/how-to-create-a-free-tiktok-feed/)

## 3. Send Blue Nova confirmation

Please send either:

- a short message saying both feeds are connected; or
- one screenshot of **Instagram Feed > All Feeds** and one screenshot of **TikTok Feeds > All Feeds**, with the saved feed visible.

Do not include any password, access token, recovery code, or private account information in a screenshot.

## What happens next

Blue Nova will:

1. Replace the temporary Homepage social previews with the two saved live feeds.
2. Show the six newest available items in each section with responsive desktop, tablet, and phone layouts.
3. Confirm that each tile opens its individual Instagram post/Reel or TikTok video.
4. Verify automatic refresh, WordPress scheduled tasks, and the website cache so new content appears without manual Homepage edits.
5. Test one new or recent item from each account and check the feed again after its refresh window.

The feeds update on a schedule rather than instantly. Public new posts should appear automatically after the plugin and website caches refresh. Draft, private, friends-only, or otherwise API-restricted content will not appear. TikTok's API may not preserve the special pinned-post order shown inside the TikTok app.

## If something does not work

- Make sure the correct social account is signed in before repeating the connection.
- If Instagram does not list the correct profile, confirm that the Instagram business/creator account is connected to the Facebook Page being selected.
- If TikTok says the domain is unauthorized, stop and send Blue Nova a screenshot of the error. Do not repeatedly reconnect it on a staging or temporary domain.
- If a feed connects but does not show new content later, tell Blue Nova. The usual causes are an expired authorization, WordPress scheduled-task issue, or website caching, not a need to rebuild the feed.
