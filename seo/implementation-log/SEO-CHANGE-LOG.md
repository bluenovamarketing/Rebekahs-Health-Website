## Verification requirements

For a live website change, record:

- Applicable cache purges
- Exact canonical public URL checked without a cache-busting parameter
- Anonymous or independent response check when practical
- Desktop and mobile visual/functional check
- Horizontal-overflow check
- Any Search Console, schema, redirect, or indexability follow-up required
