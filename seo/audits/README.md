# SEO Audits

Store dated, evidence-backed audit reports here.

Suggested filenames:

- `SEO-BASELINE-AUDIT-YYYY-MM-DD.md`
- `TECHNICAL-SEO-AUDIT-YYYY-MM-DD.md`
- `LOCAL-SEO-AUDIT-YYYY-MM-DD.md`
- `CONTENT-GAP-AUDIT-YYYY-MM-DD.md`
- `SEARCH-CONSOLE-INDEXING-AUDIT-YYYY-MM-DD.md`

Every audit should record:

- Audit date and scope
- Sources and access used
- Observed facts versus inferences
- Baseline metrics where available
- Findings ranked by impact, confidence, and effort
- Recommended next steps
- Approval or implementation status
