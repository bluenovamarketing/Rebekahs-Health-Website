# Rebekah's Health & Nutrition SEO Operations

This folder is the home for ongoing SEO strategy, research, implementation records, and reporting for Rebekah's Health & Nutrition.

Website design, development, ecommerce, and launch materials remain in their existing project locations. SEO work should link to those sources when needed rather than copying them into this folder.

## Start here

1. Review [SEO-MASTER-TRACKER.md](SEO-MASTER-TRACKER.md) for priorities, status, and current constraints.
2. Use [CHAT-STARTER-PROMPTS.md](CHAT-STARTER-PROMPTS.md) when starting a dedicated SEO chat in Codex.
3. Store work in the appropriate section below.
4. Record every implemented SEO change in [implementation-log/SEO-CHANGE-LOG.md](implementation-log/SEO-CHANGE-LOG.md).
5. After meaningful client work, update the project-level `CLIENT-NOTES.md`.

## Working rules

- Keep the website and SEO in this same Codex project so they share instructions and source files.
- Use separate SEO chats so research and reporting do not get tangled with build conversations.
- Treat audits and recommendations as read-only until implementation is specifically requested or approved.
- Capture the evidence and baseline before changing a page.
- Never assume an editor preview proves a live change. Follow the public verification and cache-purge requirements in `AGENTS.md` after every live website change.
- Keep credentials, private access details, and personal data out of this folder.
- Use **BizSuite** and <https://app.bluenovainc.com/> in all client-facing language about Blue Nova's customer platform.
