## Approval boundaries

- Research, audits, and recommendations are read-only unless the task explicitly includes implementation.
- Page-specific SEO work must use the current canonical planning-sheet row and its `Copy/Paste Prompt`.
- Live changes require cache purging and verification at the exact canonical public URL on desktop and mobile.
- Any change involving an external account, publication, or client communication follows the project-level approval rules.

## Initial recommended sequence

1. Establish a dated baseline using public evidence, current Search Console data when authorized, and the active project files.
2. Inventory existing pages, indexability, titles, headings, canonicals, structured data, internal links, and location coverage.
3. Build the keyword and search-intent map against the canonical page inventory.
4. Separate quick wins from larger page, technical, and content work.
5. Review recommendations before implementation.
6. Implement approved work in controlled batches and record verification.
7. Establish monthly reporting only after the baseline is complete.
