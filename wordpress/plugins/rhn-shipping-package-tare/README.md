# RHN Shipping Package Tare

Adds the confirmed `12 oz` prepared large-box allowance exactly once to each WooCommerce shipping package.

- Does not change product records or the client-owned inventory Sheet.
- Works with one-item and multi-item carts.
- Uses WooCommerce's configured weight unit.
- Leaves the confirmed `6 oz` small-box weight available for staff reference; the free USPS rate setup intentionally uses one conservative large-box calculation profile.
